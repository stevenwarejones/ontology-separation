# Timelike 2222: collapse to ordinary Bell screening-off

The deletion-minimal operational core in the previous increment is sharp, but
this follow-up asks whether it is genuinely a new causal structure or simply a
different route back to an ordinary Bell-local model.

For binary outcomes, any conditional expectation value in [-1,1] defines a
Bernoulli response.  The product of Alice's and Bob's screened responses gives a
normalized conditional behavior.

This increment constructs that behavior explicitly and proves:

- each hidden response is outcome-independent;
- each hidden response is parameter-independent / no-signaling;
- stable pseudo-event weights give measurement independence;
- the resulting Bell model preserves every correlator and therefore the CHSH
  score of the reduced timelike model.

So the three-law 2222 reduction embeds directly into the repository's ordinary
Bell screening-off model.

## Why this negative result matters

It tells us exactly what **not** to do next.

Simply increasing the number of settings while retaining only:

- setting-independent pseudo-event weights, and
- fully screened local response functions

will remain an ordinary local-hidden-variable construction. Any "new timelike"
inequality found there would just be a Bell inequality in different notation.

To get the distinction suggested by Mukherjee--Hance for scenarios beyond 2222,
the next model must preserve more of the asymmetric pseudo-event/operational
mediation structure instead of compressing it into complete Bell screening-off.

This is therefore an adversary result against our own abstraction: it certifies
that the current reduced model is too coarse for the hoped-for post-LF
breakthrough.
