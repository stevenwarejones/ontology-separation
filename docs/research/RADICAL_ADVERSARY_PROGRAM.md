# Post-boundary research frontier

The repository has finished the infrastructure and scoping phase:

- structured adversary search is merged;
- the adversarial boundary-map consolidation is merged;
- the Local-Agency relaxation line is closed as a negative result;
- explicit quantum record-access results are consolidated separately.

The program should now stay deliberately narrow.

## Common discovery contract

Any promoted theorem must still satisfy the same standard:

1. operationalize each premise in an explicit model, process, record, access policy, or intervention structure;
2. fix the target behavior and admissible adversary class before optimization;
3. let numerical search propose witnesses, but certify universal claims in Lean;
4. construct explicit deletion adversaries for each allegedly necessary premise;
5. prove a physical bridge from circuit/channel/process semantics;
6. stress-test access assumptions and quantifier order;
7. audit prior art after the mathematical object is fixed;
8. distinguish reproductions from genuinely new claims;
9. require independent re-derivation before any novelty claim.

A clean collapse or impossibility result is preferable to a weak positive claim.

## Active Track 1 — Return to forced-signaling

This is the primary research direction.

The Local-Agency relaxation study is now complete and explicitly says the program
returns to forced-signaling. The next work should therefore build on the existing
physical hidden-influence / LP correspondence and sharp tradeoff machinery rather
than opening more parallel speculative tracks.

Priority questions:

1. identify the strongest unresolved theorem inside the current forced-signaling
   model class;
2. tighten the physical bridge between finite-speed / hidden-influence assumptions
   and the certified LP constraints;
3. search for stronger sharp tradeoffs or impossibility regions that survive the
   strongest admissible adversary;
4. preserve exact readout, causal structure, and operational signaling distinctions
   explicitly;
5. only add new spacetime parties or geometry if they answer a theorem-level
   obstruction already visible in the current model.

The goal is not another numerical witness. The goal is a physically interpretable,
kernel-certified theorem that materially extends the current forced-signaling line.

## Active Track 2 — Baumann--Brukner physical bridge

This is the secondary, concrete formalization direction.

The repository now derives the Sec. 3 memory-change example from exact branch
amplitudes and obtains the basis-dependent flip rates internally. The remaining
gap is physical semantics rather than arithmetic.

Next steps:

1. encode the entangled source as an explicit QIT state;
2. encode Bob's basis choices as explicit projective measurements;
3. encode Wigner's unread intervention with
   `ProjectiveMeasurement.pinchingChannel`;
4. derive the same pre/post friend--Bob probability tables from Born probabilities;
5. connect those derived tables back to the deletion-minimal
   memory-awareness/no-signaling core.

Exit criterion: the concrete signaling example is derived end-to-end from the
repo's quantum state/channel/POVM semantics with no hand-entered probability table.

This remains a formalization of known prior art unless a genuinely weaker or new
assumption core emerges.

## Results to extend later, not active tracks

The explicit quantum record-access work is now a substantive consolidated result:
local access blindness, joint-access separation, two-observer disjoint-access
monogamy, redundant perfect records, and the generic perfect-copy traceout
mechanism.

Its next natural extension is imperfect/nonorthogonal record fragments and sharp
quantitative recovery thresholds. That is worth revisiting after the two active
tracks above, rather than running as a competing program.

Calibrated causal-order models and friend-specific contextuality also remain
possible future directions, but they are intentionally parked until there is a
specific theorem target that survives the boundary-map objections.

## Priority order

1. Forced-signaling: identify and prove the next sharp physical theorem.
2. Baumann--Brukner: finish the full QIT source/channel/POVM bridge.
3. Only then revisit imperfect quantum records, calibrated causal order, or
   friend-specific contextuality if a concrete theorem target has emerged.

A candidate moves beyond "benchmark" or "scope result" only after its strongest
plausible adversary fails for a proved reason.
